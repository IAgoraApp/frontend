# Lacunas do contrato para o frontend

O frontend usa o banco de demonstração para as operações descritas abaixo.
As propostas foram adicionadas à lista “Backend • A fazer” no
`iagora_backend_referencia_frontend.json`. O JSON não declara essas rotas
como implementadas.

| Recurso no frontend | Complemento documentado |
| --- | --- |
| Meu dinheiro | Consultar e atualizar a renda, reserva e data da mudança; cadastrar, listar, editar e excluir gastos atuais. |
| Metas | Guardar alvo, modo de cálculo e a estimativa que originou a meta. |
| Custos previstos | Listar, criar e excluir categorias do orçamento inicial e guardar a imagem escolhida. |
| Imóveis desejados e Meu plano | Identificar valor mensal ou total, guardar mobília e associar o plano ao imóvel. |
| Minha jornada | Guardar a imagem escolhida para a etapa pela rota existente. |
| Conversas de serviços | Listar propostas, negociar data e valor, confirmar, recusar ou retirar uma proposta. |
| Favoritos e imagens profissionais | Guardar favoritos por conta e enviar imagens usadas em logo, capa e anúncios. |

O filtro **Minhas avaliações** e a exclusão de uma execução de limpeza já
tinham operações correspondentes no contrato. As telas agora oferecem
essas ações usando os dados locais. Simulações de moradia continuam fora do
frontend, conforme a decisão de produto anterior.
